## 정보 상태 표기

| 표기 | 뜻 |
|---|---|
| `확정` | 모집공고, 법령, 고시, 공식 개통 등으로 확인됨 |
| `추진` | 예타 통과, 기본계획, 공모 선정 등 절차가 진행 중 |
| `계획` | 관계기관 또는 시행자가 발표했으나 일정·내용이 바뀔 수 있음 |

| `확인 필요` | 현재 자료만으로 확정할 수 없음 |

정확한 동·호수, 계약자 이름, 계약번호, 전화번호, 계좌정보, 서명, 신분증, 계약서 스캔본은 이 지식베이스와 향후 공개 사이트에 저장하지 않습니다. 공개 사이트는 모집공고에 적힌 실제 납부액만 제공하고 개인의 소득·보유현금·대출 가능액은 수집하거나 판단하지 않습니다.
