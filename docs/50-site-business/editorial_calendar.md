# 발행 캘린더와 입주까지의 콘텐츠 단계

## 고정 주간 편성

| 요일 | 콘텐츠 | 예시 |
|---|---|---|
| 월 | 이번 주 일정 | 공사·교통·행정·학교 일정 |
| 화 | 단지 구조 | 타입, 동선, 주차, 커뮤니티 |
| 수 | 생활권 변화 | 상가, 병원, 학교, 문화 |
| 목 | 개발계획 팩트체크 | 철도, 공원, 워라밸빌리지 |
| 금 | 원문 읽기 | 모집공고·고시·공고 1개 해설 |
| 토 | 현장 기록 | 공사사진, 산책, 보행시간 |
| 일 | 주간 요약 | 가장 중요한 변화 3~5개 |

매일 새 글을 강제하지 않습니다. 사실 변화가 없는 날은 다음 심층 글을 준비합니다.

## 2026년 하반기: 계약 직후

- 납부액·옵션·규제 원문 정리
- 26개 동과 5개 타입 구조 콘텐츠 완성
- 공식 자료 간 충돌 목록 공개
- 인천1호선 실제 이용기와 역 출구 동선
- 5호선 예타 이후 행정절차 추적
- 검단구 출범 후 생활행정 안내

## 2027년: 기초·골조 관찰기

- 월별 현장 공정 사진
- 동별 층수 변화 기록
- 학교·워라밸빌리지·나진포천 착공 추적
- 타입별 가구배치와 가전 규격 연구
- 중도금 2·3회차 일정 리마인드
- 주변 상권 성장 지도

## 2028년: 외관·생활권 구체화기

- 외벽·창호·조경·커뮤니티 공정 확인
- 2028년 개교 학교와 통학로 점검
- 중도금 4회차와 옵션 변경·확인사항
- 인테리어 품목별 시장가격 추적
- 입주예정자 질문 데이터베이스 확장
- 사전점검 체크리스트 고도화

## 2029년: 입주 준비기

- 월별로 입주 D-365, D-300, D-200, D-100 시리즈
- 사전점검, 하자, 실측, 공동구매 검증
- 잔금·옵션 90%·등기·취득세의 구분
- 이사차량·엘리베이터·주차 동선
- 학교 배정·전입·어린이집 신청
- 관리비·커뮤니티 운영안·상가 입점

## 입주 후: 생활 미디어 전환

- 월 관리비 항목 해설과 계절 비교
- 커뮤니티 예약·운영시간·프로그램
- 음식물 이송설비·주차·택배 실사용 팁
- 상가·병원·학원·배달·교통 실사용 데이터
- 하자 처리 사례와 장기수선계획
- 호수공원·나진포천 계절 콘텐츠

## 월간 최소 산출물

- 심층 해설 4편
- 상태판 업데이트 4건
- 현장 기록 1편
- 주간 요약 4편
- 기존 글 팩트체크 5편
