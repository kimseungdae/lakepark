# 검단레이크파크 정보 사이트 콘텐츠·수익화 전략

## 포지셔닝

`계약자가 공식 원문과 현장을 계속 대조하는 검단레이크파크 생활권 전문 미디어`

단순 분양 소개 사이트보다 계약 이후 3년 이상 이어지는 실제 질문을 해결하는 것이 차별점입니다.

## 핵심 독자

1. AB22·AB23 계약자와 가족
2. 예비 매수자·임차인
3. 검단신도시 신규 입주자
4. 인테리어·가전·이사·청소 정보를 찾는 사람
5. 지역 상권·서비스 사업자

## MVP 정보구조

| 메뉴 | 핵심 콘텐츠 | 재방문 이유 |
|---|---|---|
| 오늘 | 새 공지, 공사 변화, 생활권 단신 | 매일 새로운 요약 |
| 단지 | 배치, 동별 영향, 타입, 옵션, 커뮤니티 | 공사·운영 정보 업데이트 |
| 생활권 | 교통·공원·학교·상권·공공시설 상태판 | 사업 진행상태 변화 |
| 인테리어 | 옵션 비교, 실측, 견적, 가구배치 | 입주가 가까울수록 수요 증가 |
| 입주 | 실제 납부액, 사전점검, 하자, 이사, 행정 | 일정·체크리스트 사용 |
| 생활 | 병원, 교육, 통학, 교통, 상권, 주민 편의 | 입주 후 장기 검색 수요 |

## 처음 발행할 15개 콘텐츠

1. 블록·타입별 실제 납부액과 날짜 한눈에 보기
2. 주차 4,517대와 4,527대, 공식 출처가 다른 이유
3. 차량 출입구와 가까운 동은 어디인가
4. 음식물 투입구·커뮤니티와 가까운 동의 생활 영향
5. 59A와 59B 구조 차이와 가구배치 포인트
6. 84A 알파공간과 수납 활용법
7. 84B·84C 구조 차이와 맞는 가족 유형
8. 3,000평대 조경·커뮤니티와 예상 관리 항목
9. 서울5호선 연장: 예타 통과 뒤 남은 절차
10. 나진포천 친수공간은 무엇이 들어오나
11. 워라밸빌리지 최근 진행상태와 남은 변수
12. 학교 개교와 실제 통학구역이 다른 이유
13. 박물관·도서관 복합문화시설 진행상태
14. 넥스트콤플렉스 계획시설과 확정시설 구분
15. 월별 현장 공정·생활권 변화 기록

## 사이트의 핵심 기능

### 1. 실제 납부액 조회표

블록과 타입을 선택하면 모집공고 기준 공급금액 범위와 계약금·중도금·잔금의 실제 금액을 표시합니다. 개인 소득, 보유현금, 대출 가능액은 입력받지 않습니다.

- 계약 시 1,000만원
- 계약금 2차 실제 금액
- 중도금 1~6회 각 회차 실제 금액과 날짜
- 잔금 실제 금액
- 발코니·유상옵션 선택 시 계약 10%와 입주 90%
- 특별공급 1가구 때문에 생긴 최저가와 일반적인 최저가 구분

### 2. 개발계획 상태판

각 항목에 `확정/추진/계획/홍보/확인 필요`, 마지막 확인일, 원문 링크를 표시합니다.

### 3. 옵션 비교기

타입별 옵션을 선택하면 총액, 계약 시 10%, 입주 시 90%를 계산합니다. 종속 옵션도 표시합니다.

## 검색 신뢰도 원칙

- 페이지마다 작성일·수정일·팩트체크일 표시
- 출처는 본문 주장 가까이에 링크
- 예타 통과와 개통을 구분
- 실거래가와 호가를 구분
- 공식 자료를 복사하지 않고 해설·비교·계산을 추가
- 잘못된 내용의 정정 내역 공개
- 생성형 AI로 작성해도 원문을 사람이 대조한 글만 공개

## 수익화 순서

1. 원본 콘텐츠와 계산기 구축
2. 안정적인 검색 유입 확보
3. 애드센스 등 문맥형 배너
4. 인테리어·청소·이사·커튼 등 지역 업체 광고
5. 제휴 링크·견적 연결
6. 검증된 업체 디렉터리
7. 검단 다른 단지와 입주 생활권으로 확장

배너 광고는 보조 수익으로 봅니다. 한 단지의 유한한 검색량을 고려하면 업체 디렉터리, 견적 비교, 생활권 확장이 더 큰 수익원이 될 수 있습니다.

## 광고·제휴 운영 규칙

- 제목·본문 상단에 `광고`, `협찬`, `제휴 링크 포함`을 명확히 표시
- 광고비와 리뷰 평가를 분리
- 업체가 제공한 문구를 실제 이용 후기처럼 쓰지 않음
- 순위의 평가기준과 갱신일 공개
- 리드 전달 전 이용자 동의 확보
- 계약·시공 분쟁의 신고·정정 채널 운영
- 자기 광고 클릭이나 클릭 유도 금지
- 콘텐츠보다 광고가 많아지지 않도록 제한

## 개인정보·보안

- 운영자의 동·호수 비공개
- 계약서·납부내역 업로드 금지
- 현장사진 EXIF 제거
- 게시판 도입 전 신고·차단·삭제·보존정책 마련
- 견적 문의에서 최소 개인정보만 수집
- 업체에 전달할 때 별도 동의와 보유기간 안내

## 권장 첫 출시 범위

로그인·댓글·업체견적 기능 없이 다음만 먼저 공개합니다.

- 완성도 높은 글 20~30개
- 실제 납부액 조회표
- 옵션 비교표
- 개발계획 상태판
- 주간 단신과 월간 현장 업데이트
- 출처·정정·문의 페이지

커뮤니티는 운영 부담과 광고 정책 위험이 커서 트래픽과 관리체계를 확보한 뒤 추가합니다.
