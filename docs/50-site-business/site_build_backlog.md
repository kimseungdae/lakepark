# 사이트 구축 백로그

## 1단계: 콘텐츠 기반

- [ ] 사이트 이름·도메인 후보 확정
- [ ] 비공식 사이트 고지문 작성
- [ ] 지식베이스 Markdown을 웹 콘텐츠와 분리하는 빌드 구조 설계
- [ ] 글 10개 작성 및 출처 검수
- [ ] 개인정보처리방침·이용약관·정정 요청 페이지 작성
- [ ] 검색·카테고리·최근 업데이트 구현

## 2단계: 납부액·옵션 조회

- [ ] 블록·타입·층별 공급금액 데이터 구조화
- [ ] 옵션 가격 데이터 구조화
- [ ] 계약금 1·2차, 중도금 1~6회, 잔금의 실제 금액과 날짜 표시
- [ ] 특별공급 1가구 최저가와 일반적인 최저가 구분 표시
- [ ] 발코니·유상옵션 계약 10%·입주 90% 표시
- [ ] 소득·보유현금·대출 가능액 입력 기능은 만들지 않음

## 3단계: 상태판

- [ ] 개발계획 상태·확인일·출처 필드 설계
- [ ] 서울5호선, 인천1호선, 학교, 워라밸빌리지 등록
- [ ] 나진포천, 박물관·도서관, 넥스트콤플렉스, 검단구청 등록
- [ ] 오래된 정보 경고 표시
- [ ] 변경이력 공개

## 4단계: 반복 발행 체계

- [ ] 공식 출처 모니터링 목록과 확인 주기 자동화
- [ ] 일일 단신·주간 브리핑·월간 현장 기록 템플릿 적용
- [ ] 글감 100개를 상시·이벤트·계절 콘텐츠로 배분
- [ ] 게시글마다 다음 확인일과 업데이트 이력 노출
- [ ] 입주민 제보 접수·검증·정정 절차 마련

## 5단계: 수익화 준비

- [ ] 원본 콘텐츠 충분성 검토
- [ ] 광고 위치와 콘텐츠 비율 점검
- [ ] ads.txt 및 광고 플랫폼 설정
- [ ] 제휴·협찬 표시 컴포넌트 구현
- [ ] 트래픽·검색 성과 분석

## 보류

- 로그인
- 댓글·게시판
- 업체 자동 견적
- 개인 납부내역 저장
- 주민 인증

보류 기능은 개인정보·운영·분쟁 대응 설계 후 검토합니다.
