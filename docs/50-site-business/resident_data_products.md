# 입주민 재방문을 만드는 데이터 제품

글을 계속 생산하는 것보다 `상태판 → 변경 알림 → 월간 분석 → 연간 결산`으로 이어지는 데이터 제품을 먼저 만듭니다. 같은 자료를 복제하는 방식이 아니라 시간이 흐를수록 검단레이크파크만의 기록이 쌓이는 구조입니다.

## 우선 데이터 제품 8개

| 제품 | 핵심 질문 | 갱신 | 입주 전후 |
|---|---|---:|---|
| 계획 신뢰도 점수판 | 발표된 시설이 어느 행정단계까지 왔나 | 사건 발생 시 | 입주 전 |
| 도시계획 틀린그림찾기 | 지난 고시에서 도로·공원·학교·용도가 어떻게 바뀌었나 | 고시 발생 시 | 입주 전 |
| 공공조달 선행 레이더 | 착공 보도 전에 설계·감리·공사 발주가 나왔나 | 주 1회 | 입주 전 |
| 15분 생활권 완성도 | 도보생활권에 병원·보육·식품·문화기능이 얼마나 찼나 | 월 1회 | 모두 |
| 인허가→개업·폐업 파이프라인 | 새 상가가 실제 문을 열었고 얼마나 유지되나 | 주 1회 | 모두 |
| 입주 D-day 행동 달력 | 오늘 해야 할 입주 절차가 무엇인가 | D-365부터 | 입주 직전 |
| K-apt 관리비·계약 탐색기 | 관리비가 왜 변했고 어떤 계약이 체결됐나 | 월·주 | 입주 후 |
| 오늘의 레이크파크 | 날씨·대기·교통·행사·휴일의료를 한눈에 볼 수 있나 | 매일 | 입주 후 |

## 1. 계획 신뢰도 점수판

`호재`라는 단어 대신 다음 생애주기를 표시합니다.

| 단계 | 증거 | 의미 |
|---:|---|---|
| 0 언급 | 공약·홍보·검토 문구 | 사업이 시작됐다고 볼 수 없음 |
| 1 계획 | 법정계획·사업계획 반영 | 방향은 있으나 일정·예산 변동 가능 |
| 2 예산 | 본예산·추경·분담금 반영 | 실제 집행 가능성이 올라감 |
| 3 공고 | 공모·설계·감리·공사 입찰 | 수행자를 찾는 단계 |
| 4 계약 | 낙찰·사업협약·토지계약 | 상대방과 금액·범위가 구체화됨 |
| 5 착공 | 착공계·현장 공사 확인 | 물리적 공사가 시작됨 |
| 6 준공 | 준공·사용승인 | 건물·시설 공사가 완료됨 |
| 7 운영 | 개관·개통·영업·서비스 시작 | 주민이 실제 이용 가능 |

입찰공고만으로 착공이라 쓰지 않고, 준공만으로 개관이라 쓰지 않습니다.

## 2. 공공조달 선행 레이더

나라장터의 발주계획·입찰공고·낙찰·계약을 연결해 나진포천, 학교, 박물관·도서관, 도로, 공원 사업의 선행 신호를 찾습니다.

수집 필드:

- 수요기관·발주기관
- 사업명과 검색 키워드
- 공사·용역·물품 구분
- 예산·기초금액·낙찰금액
- 발주계획일·공고일·개찰일·계약일
- 변경·취소 여부
- 현장 주소와 사업 범위

나라장터 발주계획에 없더라도 입찰이나 계약이 바로 생길 수 있으므로 `발주계획 없음`을 `사업 없음`으로 해석하지 않습니다.

## 3. 도시계획 틀린그림찾기

검단신도시 개발계획·실시계획 변경고시에서 다음을 이전 도면과 비교합니다.

- 학교·유치원 부지의 위치·면적·용도
- 공원·녹지·하천 경계
- 도로 폭·교차로·보행연결
- 상업·업무·주거 용지 변경
- 공공청사·문화·주차장 부지
- 단계별 준공구역과 사업기간

원본 도면을 그대로 재배포하기보다 변경 위치를 자체 표와 해설로 표현하고 원문 PDF를 연결합니다.

## 4. 15분 생활권 완성도

단지 중심점의 반경만 그리는 대신 안전한 보행경로와 실제 영업상태를 함께 봅니다.

| 기능 | 예시 지표 |
|---|---|
| 의료 | 평일·야간·휴일 진료기관 수 |
| 돌봄 | 어린이집·유치원 정원과 운영시간 |
| 식품 | 슈퍼·마트·시장·편의점 접근시간 |
| 교육 | 학교·도서관·학원·문화프로그램 |
| 이동 | 역·버스정류장·횡단보도·경사 |
| 공공 | 행정·우편·체육·공원·화장실 |

개수만 세지 않고 `영업 중`, `도보 접근 가능`, `주말 이용 가능` 여부를 구분합니다.

## 5. 인허가에서 실제 개업까지

LOCALDATA는 전국 지자체의 식품·의료·문화·생활 등 195종 인허가를 매일 수집하며 인허가일·주소·영업상태로 개폐업 변화를 볼 수 있습니다. 이를 현장 간판과 공식 영업정보로 재확인합니다.

표시할 단계:

`인허가 → 공사·채용 → 개업 확인 → 휴업·이전 → 폐업`

인허가만 있고 영업하지 않는 곳을 신규 맛집·병원으로 소개하지 않습니다.

## 6. 검단구 인구 계기판

행정안전부 월별 주민등록 통계에서 불로·마전 생활권의 인구와 세대수, 연령구조 변화를 기록합니다. 주민등록 통계에는 외국인이 포함되지 않는 한계를 함께 표시합니다.

- 전월·전년 대비 인구와 세대수
- 세대당 인구
- 영유아·학령기·청년·고령 인구
- 1인세대 비중
- 학교·의료·상업시설 증가 속도와 비교

인구 증가를 가치 상승으로 바로 연결하지 않고 학교 과밀·교통·의료 수요 같은 생활부하도 같이 봅니다.

## 7. 입주 후 K-apt 탐색기

더샵 검단레이크파크는 100세대를 크게 넘으므로 입주 후 K-apt 관리비 공개대상입니다. K-apt는 2024-10-25부터 100세대 이상 공동주택으로 공개대상이 확대됐다고 안내합니다.

장기 콘텐츠:

- 전월·전년 동월 관리비 항목 비교
- 난방·전기·급수의 계절 변화
- 청소·경비·소독·승강기·조경 입찰과 계약
- 외부회계감사 결과
- 시설 유지관리 이력과 장기수선
- AB22와 AB23의 시설·세대수 차이에 따른 비용구조

관리비는 `발생월 → 부과월 → K-apt 공개월`이 다르므로 세 날짜를 분리합니다.

## 8. 한 변경에서 네 번 발행하기

예를 들어 박물관·도서관 공사 입찰이 나오면 다음처럼 연결합니다.

1. 변경 알림: 새 공고와 이전 단계
2. 원문 해설: 예산·범위·기간·제외항목
3. 월간 분석: 다른 생활권 사업과 진행속도 비교
4. 연간 결산: 계획에서 실제 계약·착공까지 걸린 시간

- `A`: 법령·고시·공고·모집공고
