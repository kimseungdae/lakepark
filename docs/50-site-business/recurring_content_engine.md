# 지속형 콘텐츠 생성 엔진

## 목표

검색으로 한 번 들어오는 분양 소개 사이트가 아니라, 입주 전에는 공사와 생활권 변화를 확인하고 입주 후에는 실제 생활 정보를 찾기 위해 다시 방문하는 단지 전문 미디어를 만듭니다.

## 콘텐츠 4종 구조

| 종류 | 수명 | 예시 | 역할 |
|---|---|---|---|
| 기준정보 | 장기 | 분양가, 타입, 주차, 옵션 | 검색 유입의 뼈대 |
| 상태판 | 계속 갱신 | 5호선, 학교, 공원, 공사 | 재방문의 핵심 |
| 생활발견 | 1주~수개월 | 새 상가, 행사, 버스 변경 | 매일 볼 이유 |
| 참여형 기록 | 장기 누적 | 현장사진, 설문, 실측, 하자 사례 | 단지 고유 데이터 |

## 발행 주기

### 매일

- 공식 공지와 언론 검색 결과에서 변경 1건 확인
- `오늘 바뀐 것 없음`을 억지로 글로 만들지 않음
- 행사, 교통통제, 학교 일정, 신규 상가처럼 시간가치가 있는 소식만 짧게 발행

### 매주

- 이번 주 검단레이크파크·워라밸빌리지 소식 5줄 요약
- 단지 주변 신규 상가·병원·학원·행사 정리
- 독자 질문 1개를 모집공고 원문으로 답변
- 다음 주 일정 캘린더

### 매월

- 같은 위치에서 찍은 공사사진 비교
- 단지와 나진포천·호수공원 공정 상태판
- 학교·교통·문화시설 변경이력
- 많이 읽힌 글과 오래된 글의 팩트 재검증

### 이벤트 발생 시

- 사업 공고, 착공, 준공, 개통, 입점, 통학구역 지정
- 중도금·옵션·명의변경·입주 관련 공식 안내
- 설계변경, 공사 지연, 안전사고, 교통대책

## 한 사실에서 여러 글을 만드는 방법

예를 들어 `나진포천 생태하천 착공`이 확인되면 다음 콘텐츠가 생깁니다.

1. 3분 요약: 무엇이 언제 바뀌나
2. 원문 해설: 공사범위·예산·기간 읽기
3. 지도형 글: 단지와 산책로 연결 예상지점
4. 생활영향: 공사차량·소음·보행통제
5. 월간 기록: 같은 지점 공사사진
6. 완료 후 검증: 계획과 실제 시설 비교

복제글이 아니라 독자의 질문이 다른 여섯 글입니다.

## 글감 점수

각 후보를 0~2점으로 평가해 7점 이상을 우선 발행합니다.

| 기준 | 질문 |
|---|---|
| 단지 직접성 | AB22·AB23 거주에 직접 영향을 주나? |
| 시급성 | 이번 주 안에 알아야 하나? |
| 희소성 | 다른 블로그에 없는 원문 해설인가? |
| 반복성 | 나중에 상태를 갱신할 수 있나? |
| 행동성 | 독자가 일정·구매·이동 결정을 바꿀 수 있나? |

## 제목 공식

- `[기준일] 서울5호선 연장, 이번 달 달라진 한 가지`
- `AB23 6300번대 동별 차량출입구·쓰레기시설 위치 읽기`
- `84A 알파룸을 없애면 실제로 얻고 잃는 것`
- `공식자료 두 개의 주차대수가 10대 다른 이유`
- `입주까지 D-1000: 지금 완성된 시설과 아직 계획인 시설`

## 재방문 장치

- 모든 상태판 상단에 `마지막 확인일`과 `다음 확인 예정일` 표시
- 변경 전후 표와 변경이력 제공
- 글 말미에 다음 업데이트 조건을 명시
- 주간 요약에서 심층 글로 연결
- 입주 D-day와 중도금·개발일정을 한 달력에 표시
- 사진을 같은 위치·같은 화각으로 축적

## 품질 기준

- 새 사실이 없으면 기존 글을 억지로 다시 쓰지 않습니다.
- 홍보문구는 공식 사실과 분리합니다.
- 전망 글은 긍정·지연·축소 시나리오를 함께 씁니다.
- 상가 후기는 광고·협찬·제휴 여부를 첫 화면에서 밝힙니다.
- 주민 제보는 공개 전 위치·날짜·원문을 확인합니다.
