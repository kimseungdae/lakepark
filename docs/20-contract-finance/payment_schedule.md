# 계약 이후 납부 일정

타입과 가격대별 원 단위 금액은 [블록·타입별 실제 납부액 기준표](payment_amounts_by_type.md)를 봅니다. 이 문서는 일정만 관리합니다.

## 공통 일정

| 시점 | 해야 할 일 | 금액/비율 | 확인 자료 |
|---|---|---:|---|
| 계약 시 | 1차 계약금 납부, 계약서·옵션 계약 확인 | 10,000,000원 | 공급계약서, 입금확인증 |
| 계약 후 30일 이내 | 2차 계약금 납부 | 총 분양가의 10%에서 1천만원 차감 | 개인 가상계좌 |
| 2026-12-15 | 중도금 1회 | 분양가 10% | 대출 실행 또는 자기자금 |
| 2027-06-15 | 중도금 2회 | 분양가 10% | 〃 |
| 2027-12-15 | 중도금 3회 | 분양가 10% | 〃 |
| 2028-08-14 | 중도금 4회 | 분양가 10% | 〃 |
| 2029-01-15 | 중도금 5회 | 분양가 10% | 〃 |
| 2029-06-15 | 중도금 6회 | 분양가 10% | 〃 |
| 입주지정일 | 분양대금 잔금 | 분양가 30% | 입주 안내문 |
| 입주지정일 | 발코니·유상옵션 잔금 | 각 옵션금액 90% | 옵션 계약서 |
| 입주 전후 | 취득세, 등기, 관리비 예치금 등 | 개인별 상이 | 위택스·법무사·관리사무소 |

## 지금 바로 확인할 체크리스트

- [ ] 2차 계약금 납부일과 가상계좌 확인
- [ ] 계약서상 타입·동·호·분양가를 본인 보관본에서 확인
- [ ] 발코니 확장과 유상옵션 신청·변경 마감일 확인
- [ ] 중도금대출 안내문 수신 채널 확인
- [ ] 계약금·옵션대금 영수증 이중 백업
- [ ] 달력에 중도금 6개 회차 등록
- [ ] 대출 불가 시 필요한 자기자금 시나리오 계산
- [ ] 입주 전 잔금·세금·등기·인테리어 자금 분리 적립

## 중도금대출 핵심 유의사항

- 사업주체는 중도금대출 알선 의무가 없으며 대출 승인·한도·금리·조건을 보장하지 않습니다.
- 계약금이 완납되지 않으면 중도금대출이 불가할 수 있습니다.
- 신용, 소득, 보증 한도, 금융정책 변화로 대출비율이 축소되거나 거절될 수 있습니다.
- 대출이 실행되지 않아도 계약자는 납부기일에 분양대금을 조달해야 합니다.
- 보증료·인지대·각종 수수료의 부담 주체와 이자 납부 방식을 약정서에서 확인합니다.
- 입주 전 중도금대출을 상환하거나 담보대출로 전환해야 할 수 있습니다.

## 공개 사이트 표시 원칙

- 분양가 비율만 쓰지 않고 타입·가격대별 실제 원 단위 납부액을 제공합니다.
- 개인 소득·대출·보유현금 판단은 독자에게 맡깁니다.
- 대출 가능액을 사이트가 확정하거나 추천하지 않습니다.
- 옵션 계약금 10%와 입주 시 옵션잔금 90%는 분양대금과 별도로 표시합니다.
