# 대출·세금·부대비용 체크리스트

## 총입주비용 구성

```text
총입주비용
= 분양가
+ 발코니 확장
+ 유상옵션
+ 취득세 등 제세공과금
+ 등기·법무 비용
+ 대출 보증료·인지대·설정비용·이자
+ 관리비 예치금
+ 이사·입주청소
+ 별도 인테리어
+ 가전·가구
+ 예비비
```

## 대출 확인 질문

- 집단대출 취급 금융기관과 보증기관은 어디인가?
- 분양가의 몇 퍼센트가 아니라 실제 개인 승인액은 얼마인가?
- 중도금 이자는 계약자가 매월 납부하는지, 입주 시 정산하는지?
- 보증료·인지대·중도상환수수료는 누가 부담하는가?
- 기존 신용대출·전세대출·주택담보대출이 한도에 미치는 영향은?
- 입주 시 잔금대출 전환 조건과 예상 담보평가액은?
- 소득이나 직장이 바뀌는 경우 필요한 추가 서류는?
- 2029년 실행 시점에 적용될 DSR·LTV 규정은?

현재 규정만으로 2029년 잔금대출 가능액을 확정할 수 없습니다. 금융위원회 정책, 금융기관 심사, 담보평가, 개인 부채·소득이 모두 바뀔 수 있습니다.

## 세금 확인 질문

- 계약 시점과 실제 취득 시점의 보유 주택 수는?
- 배우자와 세대원의 주택·분양권·입주권 보유 현황은?
- 발코니 확장·유상옵션 중 취득세 과세표준에 포함되는 항목은?
- 취득세 신고·납부 기한은?
- 공동명의 또는 단독명의에 따른 세금·대출·증여 이슈는?
- 자금조달계획서와 실제 자금 흐름이 일치하는가?

국세청 안내상 분양권 자체는 취득세 과세대상이 아니지만 실제 주택 취득 시 취득세가 부과되며, 분양권은 주택 수 산정에 영향을 줄 수 있습니다. 개인별 적용세율은 입주시점에 위택스·관할 지자체·세무 전문가에게 확인합니다.

## 빠지기 쉬운 부대비용

- 인지세
- 대출 보증료·근저당 설정비
- 소유권이전등기 법무비
- 채권 매입·할인 관련 비용
- 관리비 예치금
- 사전점검 대행비
- 입주청소·새집증후군 시공
- 커튼·블라인드·방충망
- 조명·가구·가전 설치를 위한 전기·타공·보강
- 이사 중 보관비와 사다리차·엘리베이터 사용료
- 입주 지연 또는 기존 주거지 계약기간 불일치 비용

## 예비비 원칙

인테리어와 가전 예산을 모두 소진하지 않고, 총 별도 지출의 일정 비율을 예비비로 남깁니다. 비율은 개인 상황에 맞춰 정하되 대출·세금·공사변경처럼 통제하기 어려운 비용을 우선 대비합니다.
