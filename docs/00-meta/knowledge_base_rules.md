# 지식베이스 운영 규칙

## 1. 출처 우선순위

1. 공급계약서 및 변경계약서
2. 청약홈 입주자모집공고와 정정공고
3. 법령, 고시, 정부·지자체·공공기관 자료
4. 사업주체·시공사 공식 발표
5. 언론 보도와 전문 서비스
6. 블로그·카페·커뮤니티

상위 출처와 하위 출처가 충돌하면 상위 출처를 사용합니다. 모집공고와 실제 계약서가 다르면 계약서를 우선 확인합니다.

## 2. 문장 작성 규칙

- 사실에는 기준일과 출처를 붙입니다.
- `예정`, `검토`, `추진`, `확정`, `개통`을 서로 바꾸어 쓰지 않습니다.
- 시공사 표현인 `역세권`, `랜드마크`, `프리미엄` 등은 사실처럼 재사용하지 않습니다.
- 가격 전망은 단정하지 않고 상승·하락 요인과 확인 지표를 함께 기록합니다.
- 법률·세금·대출 정보는 적용일과 개인별 예외 가능성을 명시합니다.
- 공개 글로 전환할 때 원문을 길게 복제하지 않고 요약과 출처 링크를 제공합니다.

## 3. 검증 상태

| 상태 | 사용 기준 |
|---|---|
| `확정` | 모집공고·계약서·법령·고시·공식 개통으로 확인 |
| `추진` | 예타 통과, 사업자 선정, 설계·착공 등 절차 진행 |
| `계획` | 공식 발표는 있으나 인허가·예산·공정상 변경 가능 |
| `홍보` | 사업주체나 판매 주체의 설명으로 독립 검증 전 |
| `의견` | 운영자의 해석 또는 시나리오 |
| `확인 필요` | 근거 부족 또는 출처 충돌 |

## 4. 날짜와 갱신

- 문서 상단에 `updated`를 적습니다.
- 변동 가능성이 큰 항목은 다음 주기로 확인합니다.
  - 대출·세금·규제: 사건 발생 시 및 분기 1회
  - 철도·도로·공원·학교: 월 1회
  - 공사현황: 월 1회
  - 옵션·계약 일정: 사업주체 공지 시 즉시
- 변경 내용은 [변경 기록](update_log.md)에 남깁니다.

## 5. 개인정보와 보안

다음 정보는 저장하지 않습니다.

- 정확한 동·호수와 거주층 조합
- 계약자 성명, 생년월일, 연락처
- 계약번호, 가상계좌, 개인 납부내역 원본
- 신분증, 인감, 서명, 주민등록 서류
- 공동현관·출입 관련 정보
- 사진의 GPS/EXIF 정보

은행 계좌처럼 공고에 공개된 정보도 요약 문서에는 옮기지 않고 원문 페이지를 안내합니다. 송금 전에는 반드시 개인 계약서와 사업주체 안내를 다시 확인합니다.

## 6. 공개 사이트 전환 전 점검

- 비공식 개인 사이트임을 명시
- 글마다 작성·수정일과 출처 표시
- 광고·제휴·협찬의 경제적 이해관계 표시
- 개인정보처리방침, 이용약관, 문의·정정 요청 채널 마련
- 공식 로고·조감도·평면도 사용 권리 확인
- 댓글·게시판 도입 시 신고·삭제·스팸 대응 체계 마련
