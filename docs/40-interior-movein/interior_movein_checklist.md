# 인테리어·사전점검·입주 체크리스트

## 지금~공사 중

- [ ] 타입별 기본·확장 평면도 보관
- [ ] 유상옵션 최종 선택서 보관
- [ ] 가구·가전 크기 후보 목록 작성
- [ ] 입주 후 시공 가능한 항목과 불가능한 항목 구분
- [ ] 현장사진은 월별·촬영위치별로 정리하고 GPS 정보 제거
- [ ] 인테리어 예산을 필수·선호·보류로 분리

## 옵션 선택 시 우선 확인

- 시스템에어컨 미선택 시 기본 냉매배관 범위
- 실외기실 공간과 추가 실외기 설치 제한
- 주방 옵션에 포함·제외되는 인덕션·후드·상판·가구
- 발코니·다용도실의 배수·난방·단차
- 붙박이장 뒤 벽·바닥 마감 여부
- 디자인월의 TV 설치·보강·타공 제한
- 실링팬과 조명 옵션의 종속관계
- 냉장고 옵션 미선택 시 제공되는 가구장 치수

## 별도 인테리어 후보

| 항목 | 신축에서 확인할 점 | 급하지 않은 경우 |
|---|---|---|
| 줄눈 | 욕실·현관·발코니 타일 상태 | 입주 후 부분 시공 가능 |
| 탄성코트 | 결로 원인 해결이 우선 | 필요 공간만 선택 |
| 중문 | 기본 동선·가구 반입폭 | 옵션과 외부시공 비교 |
| 필름 | 기본 마감의 내구성과 AS | 하자 처리 후 진행 |
| 조명 | 기본 조도·스마트 제어 호환 | 입주 후 교체 가능 |
| 커튼·블라인드 | 실측 후 주문 | 사전점검 전 발주 금지 |
| 방충망 | 기본 사양·창호 AS 영향 | 안전·방범 제품 검토 |
| 가구 | 콘센트·문 열림·로봇청소기 동선 | 실측 후 제작 |

## 사전점검

모집공고는 입주지정기간 시작 45일 전까지 2일 이상 사전방문을 실시할 예정이라고 안내합니다. 정확한 일정은 별도 통보됩니다.

### 준비물

- 계약서상 타입과 옵션 선택표
- 평면도·콘센트·가구 배치 메모
- 휴대폰, 보조배터리, 줄자, 수평계 앱
- 포스트잇·마스킹테이프·펜
- 물티슈·휴지·장갑·실내화
- 하자 기록 양식

### 점검 구역

- 현관문·도어락·중문·신발장
- 창호 개폐·잠금·유리·실리콘·결로 흔적
- 벽·천장·바닥의 균열·들뜸·오염·수평
- 붙박이 가구의 문짝·서랍·마감·고정
- 주방 상판·수전·배수·가전 공간·콘센트
- 욕실 방수·배수·수압·타일·환풍기
- 발코니·다용도실 배수·단차·수전
- 난방·환기·에어컨·월패드·조명·콘센트
- 피난구·감지기·소화설비의 간섭 여부

하자는 위치가 보이는 전체 사진, 결함 확대사진, 동작 영상으로 남기고 번호를 붙입니다.

## 입주 3개월 전

- [ ] 잔금대출 사전상담과 필요서류 확인
- [ ] 취득세·등기·법무 비용 재계산
- [ ] 옵션 잔금과 분양대금 잔금 분리
- [ ] 이사업체·입주청소 견적 비교
- [ ] 가전·가구 실측 예약
- [ ] 기존 집 계약 종료일과 입주지정일 간격 확인
- [ ] 인터넷·TV·정수기·가스 등 설치 가능일 확인
- [ ] 관리비 예치금과 엘리베이터 예약 확인

## 입주 후

- [ ] 하자 접수번호와 보수 결과 기록
- [ ] 취득세 신고·납부 확인
- [ ] 소유권이전등기 진행 확인
- [ ] 전입·학교·차량등록 등 행정업무
- [ ] 관리규약·커뮤니티 운영시간·이용료 확인
- [ ] 실제 난방·환기·소음·주차 경험 기록
- [ ] 공개 후기 작성 시 동·호수·사진 위치정보 삭제
