# 스마트홈·보안·인증의 실제 조건

`스마트홈 제공`이라는 홍보문구를 실제 작동조건, 무료기간, 보안설비 범위로 나눠 봅니다.

## 앱 원격제어 조건

- 앱의 일괄소등·가스차단 원격제어에는 입주자대표회의가 별도 단독 IP 인터넷 회선을 설치해야 합니다.
- 공동현관 자동문열림과 주차위치 안내는 앱 실행, 인터넷과 블루투스가 필요합니다.
- 정확한 주차위치 안내에는 위치정보 동의가 필요합니다.
- 더샵 앱으로 세대 현관 도어락을 직접 여는 기능은 제공되지 않습니다.
- NFC 카드·스마트폰을 도어락에 임의 등록하는 방식은 동일 인식번호 위험 때문에 공고에서 권장하지 않습니다.
- 음성인식 스피커는 기본 제공되지 않습니다.

입주 후에는 스마트홈 장애를 앱 문제, 단지 인터넷 회선, 세대 네트워크, 외부 플랫폼 중 어디에서 발생했는지 구분해야 합니다.

## 무료기간과 서비스 종료 가능성

| 서비스 | 공고상 무상기간 | 이후 확인할 것 |
|---|---:|---|
| 외부 스마트홈 플랫폼 연동 | 입주일부터 3년 | 유료화·기능축소·중단 여부 |
| 현대·기아차 플랫폼 연동 | 입주일부터 1년 | 연장비용·지원차종·중단 여부 |
| 더샵 앱·단지 홈페이지 | 입주기간 종료 후 3년 | 운영주체·유지비·대체시스템 |
| 헬스케어 서비스 | 1년 | 장비 회수·재계약·이용료 |

무상기간은 영구 제공을 뜻하지 않습니다. 입주 1년·3년 시점은 사이트의 중요한 갱신 이벤트입니다.

## 저층·최상층 보안

- 동체감지기는 공고상 1·2층과 최상층 세대에 설치됩니다.
- 배터리 교환주기는 통상 1년으로 안내됩니다.
- 저층 세대에 방범창이 기본 설치되는 것은 아닙니다.
- CCTV는 설치돼도 배치상 사각지대가 생길 수 있다고 공고에 안내돼 있습니다.

저층 보안 콘텐츠는 창호 잠금, 센서 범위, 조경 시선차단, 경관조명과 사생활보호를 함께 봅니다.

## 내진·녹색건축 인증

AB22·AB23 공고에 기재된 예비·설계단계 기준입니다.

| 항목 | 내용 |
|---|---|
| 내진등급 | 1등급 |
| 메르칼리 진도 | VII |
| 최대지반가속도 | 0.204g |
| 녹색건축 예비인증 | 최우수, 그린 1등급 |

인증등급은 `지진 피해가 없다`거나 `관리비가 무조건 낮다`는 뜻이 아닙니다. 최종 인증서, 실제 에너지 사용량과 유지관리 결과를 입주 후 대조합니다.

## 입주 후 갱신할 상태판

- 단지 인터넷 회선 설치와 월 유지비
- 앱별 실제 지원기능·장애·종료일
- 차량 플랫폼 지원차종과 이용료
- 동체감지기 배터리 교체주기
- CCTV 사각지대 개선
- 최종 녹색건축·에너지 인증
- 실제 공용전기와 난방 사용량
