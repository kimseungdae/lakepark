# 동별 생활영향·소음·출입구 체크

모집공고에 직접 적힌 동별 시설 인접 정보를 정리했습니다. 개인 계약자의 동·호 정보와는 무관한 공개 자료입니다. 위치는 시공 중 변경될 수 있으므로 입주 전 최종 배치도와 준공도서로 갱신합니다.

## 층·위치별 공통 영향

### 저층

- 출입구, 필로티, 중앙광장, 어린이놀이터, 주민운동시설 이용자의 시선과 소음
- 조경수, 문주, 옹벽, 상가, 환기구로 인한 조망·채광 간섭
- 차량 출입구·비상차로·경관조명·가로등의 빛과 알람 소음
- 필로티 상부 세대의 바닥난방 효율 저하 가능성

### 중층

- 놀이터·운동시설 소음은 거리에 따라 중층까지 전달될 수 있음
- 승강기 샤프트 인접 침실의 운행음 확인 필요
- 동 간 마주보기와 측면 창 시선 간섭 확인 필요

### 고층·최상층

- 옥상 태양광 패널 반사와 경관·항공장애 조명 영향 가능
- 옥탑 기계실·환기설비·통신중계기 인접 시 소음 가능
- 주변 후속 개발로 조망이 달라질 수 있음

## 실제 확인 순서

1. 모집공고의 동별 유의사항 확인
2. 계약 카탈로그 단지배치도에서 시설 위치 대조
3. 최종 사업계획승인도서와 준공도서의 변경 여부 확인
4. 입주자 사전방문 때 소음원·조명·환기구·쓰레기 동선 현장 확인
5. 입주 후 관리사무소 운영시간과 수거시간 확인

안테나·중계기, 사생활보호필름과 남측 대지경계는 시공 중 변경될 수 있으므로 최종 준공도면을 확인하기 전에는 확정 위치로 단정하지 않습니다.

## 블로그 글감

- 우리 동 아래에는 어떤 커뮤니티가 들어오나
- 음식물 이송설비가 있어도 지상 투입구가 필요한 이유
- 차량 출입구 인접동은 무엇을 확인해야 하나
- 저층에서 조경은 장점일까 조망 간섭일까
- 필로티 상부 세대의 난방과 소음 체크법
- 최상층의 태양광 패널·기계실 영향 읽는 법
