# 자동 리서치 수집함

이 폴더는 검단레이크파크 관련 정보를 자동으로 수집하는 **후보 보관함**입니다. 이곳의 항목은 블로그 글이나 확정 사실이 아닙니다.

## 수집 원칙

- 공식 기관·공식 분양 홈페이지·시공사·공공데이터 원문만 기록합니다.
- 새 정보 또는 이전 기록과 달라진 정보만 기록합니다.
- 모집공고, 고시, 공고, 사업페이지의 URL·발표일·확인시각을 남깁니다.
- 계획·예산·공고·계약·착공·준공·운영을 구분합니다.
- 개인 동·호수, 계약자 정보, 제보자의 개인정보는 절대 기록하지 않습니다.
- 블로그 본문, 전망 판단, 광고 문구, 개인 자금 조언은 작성하지 않습니다.
- 기존 `docs/` 지식베이스는 저녁 검토 전에는 수정하지 않습니다.

## 일일 파일 형식

파일명은 `YYYY-MM-DD.md`입니다. 자동 수집은 같은 날짜 파일의 마지막에 다음 형식으로 추가합니다.

```markdown
## HH:MM KST — 후보 제목

- 상태: 계획/예산/공고/계약/착공/준공/운영/확인 필요
- 기관: 
- 원문 발표일: 
- 확인시각: 
- 원문: URL
- 새로 확인한 사실: 
- 이전 기록 대비 변화: 
- 관련 문서: `docs/...`
- 저녁 검토 포인트: 
```

## 저녁 검토 순서

1. 원문을 직접 열어 수치·날짜·상태를 대조합니다.
2. 기존 `docs/`에 이미 있는 정보인지 확인합니다.
3. 주민 생활에 미치는 영향과 다음 확인 조건을 작성합니다.
4. 유효한 항목만 지식베이스와 블로그 초안으로 승격합니다.
