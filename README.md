# 분양 아파트 총비용 계산기

계약금·중도금·잔금에 취득세, 등기비, 옵션 잔금, 인테리어까지 더해
**언제 얼마의 현금이 필요한지**를 시점별로 계산하는 정적 웹 도구입니다.

더샵 검단레이크파크 AB22BL·AB23BL 프리셋이 기본 탑재되어 있지만,
계산 로직은 단지에 종속되지 않습니다.

## 왜 이 형태인가

원래 구상은 "단지 정보 사이트 + 배너 광고"였으나 적합성 검사 결과 부적합으로 판정했습니다.

| 판정 근거 | 내용 |
|---|---|
| 타이밍 | 입주가 2029년 12월. 인테리어·사전점검·이사 콘텐츠는 3년 넘게 수요가 없음 |
| 이해충돌 | 계약 당사자가 쓰는 "시세 전망"은 구조적으로 상승 편향 |
| 경쟁 | 호갱노노 단지 커뮤니티가 이미 활발하고, 입주예정자 카페는 향후 공식 채널로 승격 |
| SEO | 네이버가 개인 신규 도메인을 사실상 노출하지 않음. 초기 콘텐츠 후보는 이미 선점됨 |
| 수익 | 배너 기준 월 1.2~3.6만원, 투입 450시간 → 시급 약 2천원 |

살아남은 요소는 **계산기** 하나입니다. 네이버 카페·블로그가 구조적으로 만들 수 없고,
공고 기준표로 정확도를 검증할 수 있는 유일한 물건이기 때문입니다.

**3년간 KPI는 PV가 아니라 구독자 수입니다.** 인테리어·이사 리드 시장은 2029년에 열립니다.

## 리스크를 권고가 아닌 구조로 막는다

| 리스크 | 구조적 조치 | 위치 |
|---|---|---|
| 상표권 | 사이트명·도메인에 브랜드명 미사용. 단지명은 데이터 값으로만 | `src/data/site.ts` |
| 저작권 | 도면·조감도 디렉터리를 아예 만들지 않음 | `.gitignore` |
| 명예훼손 | 시공사·업체 평가 콘텐츠 없음. 금액만 다룸 | 범위 밖 |
| 개인정보 | 서버·DB 없는 정적 사이트. 구독은 외부 위탁 | `astro.config.mjs` |
| 표시광고법 | MVP에 광고·제휴 없음 → 대가성 표시 의무 미발생 | — |
| 오정보 | 모든 세율·요율을 기준일·출처와 함께 단일 파일로 격리 | `src/data/rates.ts` |

## 정확도가 유일한 해자다

`tests/golden.test.ts`가 입주자모집공고 기준표와 계산 결과를 원 단위로 대조합니다.
검증에는 **공개된 공고 값만** 씁니다 — 개인 계약 세대의 동·호·금액은 저장소에 남기지 않습니다.

```
AB23BL 84A 최고가 662,700,000원
  계약 시        10,000,000    ✓
  30일 이내      56,270,000    ✓
  중도금 ×6      66,270,000    ✓
  입주지정일    198,810,000    ✓
```

## 구조

```
src/
  lib/calc/        ← 프레임워크 import 금지. 순수 TS 함수만.
    schedule.ts      계약금·중도금·잔금 + 유상옵션 별도 트랙
    acquisitionTax.ts 취득세·지방교육세·농어촌특별세
    loanInterest.ts   중도금 대출 일할 이자
    moveInCosts.ts    입주 부대비용 추정 구간
    total.ts          확정/추정 분리 및 시점별 현금 버킷
  data/
    rates.ts         세율·요율 + asOf + sourceUrl
    presets/         단지별 공고 데이터
  pages/           index / about / privacy
```

계산 로직에 프레임워크 의존을 두지 않은 것은 3년 이상 유지해야 하기 때문입니다.
스택을 갈아타도 `src/lib/calc/`와 테스트는 그대로 이식됩니다.

## 명령

```bash
npm run dev        # 개발 서버
npm test           # 계산 로직 + 골든 테스트
npm run typecheck  # 타입 검사 (.ts)
npm run build      # 정적 산출물
```

`npm run typecheck`는 `tsconfig.check.json`을 씁니다.
`@astrojs/check`가 TypeScript 7을 아직 지원하지 않아(peer `^5||^6`) `.ts`만 검사하며,
`.astro` 파일의 오류는 `npm run build`가 잡습니다.

## 아직 확정되지 않은 값

| 항목 | 상태 |
|---|---|
| 중도금 무이자 여부·이자 부담 주체 | 공고는 알선 비보장만 명시. **확인 필요** |
| 입주지정일 | 2029-12-01로 추정. 입주안내문으로 확정 예정 |
| AB22BL 발코니 확장·유상옵션 가격표 | 미정리 (공고 2026000194) |
| 옵션의 취득세 과세표준 포함 범위 | 세무 확인 대상. 기본값은 포함 |
| 전매제한·실거주의무 | UI 미반영 |

다주택 중과세율(8%·12%)은 의도적으로 지원하지 않습니다.

## 배포 전 설정

`src/data/site.ts`에서 채웁니다.

- `stibeeFormAction` — 비어 있으면 구독 섹션이 렌더링되지 않습니다
- `cloudflareAnalyticsToken` — 비어 있으면 계측 스크립트를 넣지 않습니다
- `url` — 실제 도메인 (**브랜드명 없는 도메인을 쓸 것**)

## 중단 기준 (Kill criteria)

> 공개 후 **3개월 내 계산기 완료 사용 500회 또는 구독자 100명** 미달 시 중단한다.

- 공개 기준일: _(배포 시 기록)_
- 판정 예정일: _(공개일 + 3개월)_

미달이면 접습니다. 사전에 합의한 기준이며 나중에 완화하지 않습니다.

## 고지

개인이 만든 비공식 참고 도구입니다. 시공사·시행사·분양사와 아무런 관계가 없습니다.
모든 금액은 입주자모집공고와 공급계약서가 우선하며,
대출 가능 여부와 세액은 금융기관·위택스·세무 전문가의 확인이 필요합니다.
